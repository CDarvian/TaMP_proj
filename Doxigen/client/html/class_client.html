Detailed Description

Класс, реализующий клиентское TCP-соединение с использованием паттерна Singleton.

Предоставляет методы для подключения к серверу, отправки команд и получения ответов. Все взаимодействие происходит через QTcpSocket. При получении данных эмитируется сигнал msgFromServer(), передающий строку без служебных символов \r
.
