Detailed Description

Класс, представляющий окно регистрации и авторизации пользователя.

Позволяет пользователю:

  • Зарегистрироваться
  • Войти в систему
  • Посмотреть статистику

После успешной авторизации открывает главное окно с дополнительными функциями.
